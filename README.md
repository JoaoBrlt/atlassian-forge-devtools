# Atlassian Forge DevTools

![Banner](docs/images/banner.png)

Browser extension that provides DevTools for Atlassian Forge apps.

## Download

- [Download for Chrome](https://chromewebstore.google.com/detail/atlassian-forge-devtools/nofccjajldmajgiidomkffhdecihiaig)
- [Download for Firefox](https://addons.mozilla.org/addon/atlassian-forge-devtools)
- [Manual download](https://github.com/JoaoBrlt/atlassian-forge-devtools/releases)

## Features

- View Forge Function invocations.
- View Forge Remote invocations.
- View Forge tRPC requests.
- Edit and resend requests.
- Filter requests by name.
- Configure the visible columns.
- Import HAR files.
- Export HAR files.
